## ✨ معرفی پروژه

**EdgePulse AI Agent V8.0 PRO** یک عامل هوش مصنوعی سازمانی و مقیاس‌پذیر بدون نیاز به سرور (Serverless) است که مستقیماً بر روی شبکه ابری Cloudflare Workers اجرا می‌شود. این ربات با الهام از نرم‌افزارهای محبوب مدیریت ارائه‌دهنده‌های هوش مصنوعی مانند **OpenCode**، **Cherry Studio** و **Chatbox** بازطراحی شده و تجربه کاربری بدون نقصی را برای اتصال انواع ارائه‌دهندگان، تست زنده مدل‌ها، و گفتگوی متنی و چندرسانه‌ای به ارمغان می‌آورد.

## 🚀 ویژگی‌های کلیدی

### ۱. راه‌اندازی بدون دستکاری کد (Zero-Code Web Onboarding)
- **بدون افشای توکن در سورس‌کد:** نیازی به درج توکن ربات تلگرام یا آی‌دی عددی ادمین داخل فایل‌های پروژه نیست.
- **صفحه راه‌اندازی تعاملی (`/setup`):** پس از دیپلوی ورکر، با باز کردن آدرس آن در مرورگر، توکن ربات و آی‌دی ادمین را وارد کرده و با یک کلیک وب‌هوک تلگرام به طور خودکار ست می‌شود.
- **ایمن در برابر دسترسی غیرمجاز:** توکن‌های ذخیره‌شده به شکل امن در KV نگهداری می‌شوند.

### ۲. موتور اتصال چند ارائه‌دهنده (Multi-Provider Engine)
- **پشتیبانی از پروتکل‌های استاندارد:** سازگار با تمامی ارائه‌دهندگان سازگار با OpenAI، از جمله:
  - Google Gemini (Google AI Studio)
  - Groq (Ultra-Fast Inference)
  - OpenRouter (100+ Free & Paid Models)
  - DeepSeek (Reasoning & Chat)
  - Cloudflare AI Gateway، ارائه‌دهنده‌های CCR و پروکسی‌های اختصاصی
- **تشخیص و اصلاح هوشمند آدرس پایه (Smart Base URL Probing):** سیستم به شکل کامپایلری ساختار URL را تحلیل کرده و در صورت ناقص بودن مسیرهایی مثل `/v1` یا اسلش‌های اضافی، به شکل خودکار مسیر صحیح را کشف و تنظیم می‌کند تا کاربر با ارورهای متداول مواجه نشود.

### ۳. تفکیک مدل‌های رایگان و تست زنده (Free Models & Live Ping)
- **شناسایی خودکار مدل‌های رایگان:** تفکیک هوشمند مدل‌های بدون هزینه (`:free`، مدل‌های رایگان گوگل و Groq) با برچسب بصری 🟢 FREE.
- **تست پینگ و سلامت زنده (Live Latency Benchmark):** قابلیت ارسال پرامپت تستی زنده در پنل مدیریت وب برای سنجش میلی‌ثانیه‌ای تاخیر پاسخ‌دهی و پایداری هر ارائه‌دهنده.

### ۴. سیستم ضد لیمیت، ضد بن و ضد اسپم (Enterprise Hardening)
- **مدیریت خطاهای ۴۲۹ (Adaptive Exponential Backoff):** در صورت افتادن لیمیت از سوی یک ارائه‌دهنده، درخواست‌ها با تاخیر فزاینده هوشمند مجدداً تلاش شده یا به مدل/کلید جایگزین هدایت می‌شوند.
- **بازیابی خودکار پارامترهای مدل‌های تفکرگر (Reasoning Auto-Healing):** تصحیح خودکار پارامترهای ناسازگار (مانند `temperature` در مدل‌های رده فکری مثل o1/o3/DeepSeek-R1) برای جلوگیری از ارور ۴۰۰.
- **صف ضد اسپم و قفل ایزوله کاربر (Per-User Concurrency Locking):** جلوگیری از ارسال رگباری پیام‌ها و مصرف منابع ناخواسته.

### ۵. مدیریت چندحالته شخصیت و سشن‌ها (4-Mode Soul & Sessions)
- **حالت‌های اختصاصی:**
  - 💬 **گفتگو و چت روزمره (Chat Mode):** لحن صمیمی، روان و مستقیم.
  - 💼 **محیط کاری و تحلیل پروژه (Work Mode):** کدنویسی، تحلیل داکیومنت‌ها و امور فنی.
  - 🎭 **شخصیت سفارشی (Custom Mode):** تعریف پرامپت سیستم دلخواه با قابلیت تنظیم در وب‌اپ.
  - 👤 **مهمان (Guest Mode):** پاسخ‌دهی رسمی با محدودیت‌های قابل کنترل برای کاربران عمومی.
- **سشن‌های ایزوله:** هر کاربر دارای تاریخچه حافظه مستقل، امکان ریست تاریخچه (`/clear` یا `/new`) و دکمه‌های شیشه‌ای تعاملی است.

## 🛠️ پیش‌نیازها

1. یک حساب رایگان در [Cloudflare](https://dash.cloudflare.com/)
2. نصب [Node.js](https://nodejs.org/) (نسخه ۱۸ به بالا)
3. ابزار خط فرمان [Wrangler](https://developers.cloudflare.com/workers/wrangler/install-and-update/)
4. یک ربات تلگرام ساخته شده در [BotFather](https://t.me/BotFather)

## 📦 نحوه راه‌اندازی و دیپلوی

### روش اول: استقرار سریع با Wrangler CLI

۱. **کلون کردن مخزن:**
```bash
git clone https://github.com/<your-username>/edgepulse.git
cd edgepulse
```

۲. **ورود به حساب Cloudflare:**
```bash
npx wrangler login
```

۳. **ساخت فضای ذخیره‌سازی KV:**
```bash
npx wrangler kv:namespace create "BOT_KV"
```
*خروجی دستور بالا شامل یک `id` است. آن را در فایل `wrangler.toml` جلوی `id` قرار دهید:*
```toml
[[kv_namespaces]]
binding = "BOT_KV"
id = "شناسه_دریافتی_از_دستور_بالا"
```

۴. **استقرار (Deploy):**
```bash
npx wrangler deploy
```

۵. **راه‌اندازی بدون دستکاری کد:**
پس از اتمام دیپلوی، آدرس ورکر به شما نمایش داده می‌شود (مثلاً `https://edgepulse.your-subdomain.workers.dev`).
آدرس را در مرورگر باز کنید یا به انتهای آن `/setup` اضافه کنید:
- توکن ربات تلگرام دریافتی از BotFather را وارد کنید.
- آیدی عددی تلگرام خود (ادمین) را وارد کنید.
- روی دکمه **"ثبت و راه‌اندازی خودکار"** کلیک کنید.
- وب‌هوک ربات به طور خودکار فعال شده و ربات شما آماده پاسخ‌گویی است!

---

### روش دوم: کپی مستقیم در پنل وب Cloudflare Workers

۱. وارد داشبورد Cloudflare شوید و به بخش **Workers & Pages** بروید.
۲. یک ورکر جدید با نام دلخواه (مثلاً `edgepulse`) بسازید.
۳. در تب **Settings > Variables & Bindings**، یک KV با نام بایندینگ `BOT_KV` ایجاد و متصل کنید.
۴. دکمه **Edit Code** را زده و محتویات فایل [`worker.js`](worker.js) را درون ادیتور جایگزین و ذخیره کنید (**Deploy**).
۵. آدرس ورکر را در مرورگر باز کرده و اطلاعات ربات را در صفحه `/setup` وارد کنید.

## 📱 دستورات ربات در تلگرام

| دستور | عملکرد |
| :--- | :--- |
| `/start` | راه‌اندازی اولیه و نمایش منوی دکمه‌های شیشه‌ای |
| `/help` | راهنمای کامل استفاده از امکانات و دستورات |
| `/model` | انتخاب یا تغییر مدل هوش مصنوعی فعال |
| `/mode` | جابجایی بین حالت‌های شخصیتی (چت، کار، سفارشی، مهمان) |
| `/clear` یا `/new` | پاک‌سازی تاریخچه مکالمه سشن فعلی |
| `/status` | نمایش وضعیت اتصال، ارائه‌دهنده فعال و میزان تاخیر |
| `/panel` | دریافت لینک ورود امن به پنل مدیریت وب‌اپ |

## 🖥️ پنل مدیریت وب (Web Mini-App & Admin Dashboard)

با باز کردن صفحه اصلی ورکر (`/app` یا `/`) یا دستور `/panel` در ربات، به داشبورد مدیریتی دسترسی خواهید داشت:
- ➕ **افزودن ارائه‌دهنده دلخواه (Custom Provider):** ثبت Base URL، API Key و واکشی خودکار تمام مدل‌ها.
- ⚡ **تست زنده مدل‌ها (Latency & Probe):** تست اعتبار کلید و سرعت پاسخ‌دهی قبل از فعال‌سازی روی ربات.
- 🧠 **شخصی‌سازی پرامپت‌ها (Soul Management):** تنظیم دقیق سیستم پرامپت هر یک از ۴ حالت رفتاری.
- 👥 **مدیریت کاربران و دسترسی‌ها:** مشاهده و کنترل دسترسی اعضا و گروه‌ها.

## 🔒 امنیت و حریم خصوصی

- هیچ‌گونه توکن، کلید API یا اطلاعات حساسی در سورس‌کد پروژه قرار ندارد.
- تمامی ارتباطات میان تلگرام، کلاودفلر و ارائه‌دهندگان هوش مصنوعی با پروتکل HTTPS رمزنگاری شده است.
- سیستم محدودسازی نرخ درخواست (Rate Limiting) و قفل هم‌زمانی، ربات را در برابر حملات محرومیت از سرویس (DoS) و جریمه‌های تلگرام محافظت می‌کند.
